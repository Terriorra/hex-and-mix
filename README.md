# Название игры: Hex & Mix

## 1. Общее описание (Концепт)
Двумерная браузерная игра в атмосфере Хэллоуина. Игрок выступает в роли ведьмы, которая экспериментирует с ингредиентами в магическом котле для создания зелий. 

* **Жанр:** Алхимия, симулятор крафта, кликер.
* **Платформа:** Web (разрешение под один фиксированный экран, адаптивное под Itch.io).
* **Технологии:** Чистый JavaScript (Vanilla JS), HTML5, CSS3, SVG (графика).

## 2. Игровой процесс (Геймплей)
Вся игра происходит на одном экране (комната ведьмы). В центре экрана стоит магический котёл.

### Основные действия игрока (Core Loop):
1. **Включение горелки:** Поддержание огня под котлом (влияет на температуру / готовность).
2. **Добавление ингредиентов (Drag-and-Drop):** Перетаскивание колбочек, травок и предметов с полок на стенке прямо в котёл.
3. **Перемешивание:** Активное взаимодействие с варевом с помощью ложки/мутовки.
4. **Постукивание по котлу (Клик):** Особое действие (может ускорять реакцию, добавлять «магии» или стабилизировать зелье).

### Финал цикла варки:
Когда игрок решает, что зелье готово, он кликает на **специальную пустую колбочку**. 
* Варево переливается в колбу.
* Происходит расчет характеристик получившегося раствора на основе добавленных предметов, температуры и перемешивания.
* Игрок получает новый предмет/зелье с уникальными свойствами.

## 3. Вектор развития (Что можно добавить позже)
* **Режим Аптеки / Лавки:** Продажа получившихся зелий клиентам (ведьмам, вампирам, оборотням) за монеты.
* **Книга Рецептов:** Справочник, где открытые зелья сохраняются, чтобы игрок видел свой прогресс.
* **Система Изучения:** Механика исследования характеристик полученных зелий с помощью специального микроскопа или магического кристалла.
* **Апгрейды:** Покупка новых полок, улучшенных котлов или редких ингредиентов за заработанное золото.
